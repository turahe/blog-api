# Roadmap

## Phase 1: Foundation

- project bootstrap
- configuration and environment handling
- PostgreSQL and Redis connectivity
- health endpoints
- auth foundation
- user, role, and permission model

## Phase 2: Content Core

- posts
- categories
- tags
- media upload and listing
- public read APIs
- Redis caching for public reads

## Phase 3: Collaboration and Moderation

- comments
- moderation workflow
- audit logging improvements
- notification hooks

## Phase 4: Event-Driven Platform

- Watermill event publishing
- durable outbox
- workers and jobs
- transformed media cache strategy
- operational hardening

## Phase 5: Product Expansion

- richer admin UX
- search integration
- admin analytics dashboard
- privacy and consent management
- media pipeline improvements

## Phase 6: Analytics and Reporting

- page view, time spent, and navigation telemetry
- popular content and retention widgets
- search analytics and CTR reporting
- real-time admin activity views
- analytics data export and retention controls
